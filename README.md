# Stock Strategy Lab

겸업 투자자를 위한 개인 투자전략 설계 · 백테스트 · 자동화 프로젝트.

유명 투자자들의 전략을 분석해 장점을 통합하고, 시장 상황에 따라
장기/중기/단기 축을 유연하게 조합하는 것을 목표로 한다.

## 구조

```
docs/
  01-investor-strategies.md   # 유명 투자자별 전략 정리 + 통합 전략 초안
  02-short-term-rules.md      # 단기(추세추종) 축 매매 규칙 + 진행 로그
backtest/
  trend_following_backtest.py # 단기 축 백테스트 엔진 (그리드서치/워크포워드 포함)
```

## 지금까지 진행 상황

1. 유명 투자자(가치/성장/매크로/추세추종) 전략 정리 및 시장 국면별 매핑 완료
2. 장기:중기:단기 = 30~40% 균형 배분 + 국면별 비중 조절 프레임 확정
3. 단기 축(터틀 스타일 추세추종) 매매 규칙 확정
4. 백테스트 엔진 구현 및 합성 데이터로 로직 검증 완료
5. 파라미터 그리드서치 + 워크포워드 검증 모듈 구현 완료
