# 유명 투자자별 전략 정리

목표: 한 스타일을 고집하지 않고, 시장 상황에 맞게 장기/중기/단기 축을 조합해
자동화까지 이어지는 나만의 투자 원칙을 만든다.

## 1. 가치투자 계열 (장기)

- **벤저민 그레이엄**: 내재가치 대비 충분히 싼 가격(안전마진)에 매수.
  PER, PBR 등 정량 지표 기반 스크리닝.
- **워런 버핏**: 안전마진 + "훌륭한 기업을 적정가에". 경제적 해자, 신뢰할 수
  있는 경영진, 장기 보유.
- **하워드 막스**: 시장 사이클(강세/약세, 고평가/저평가) 진단을 항상 병행.

## 2. 성장주 투자 계열 (중기)

- **피터 린치**: "자신이 잘 아는 기업에 투자하라." PEG 비율로 성장 대비
  저평가 여부 판단. 텐배거(10루타) 발굴.
- **필립 피셔**: 정성적 분석(경영진, R&D, 시장 지위) 기반 장기 성장주 발굴.
- **윌리엄 오닐(CANSLIM)**: 실적 성장 + 기술적 모멘텀 결합 스크리닝.
- **마크 미너비니(SEPA)**: 추세 템플릿(이동평균 위, 신고가 근접) 기반 모멘텀
  성장주 발굴.

## 3. 매크로·자산배분 계열 (국면 대응)

- **레이 달리오(올웨더)**: 경제 국면(성장/인플레이션 4분면)별 리스크 패리티
  자산배분. 시장 상황에 따라 전략 비중을 바꾸는 프레임워크의 핵심 참고.
- **조지 소로스(반사성 이론)**: 시장 심리와 펀더멘털의 되먹임에 베팅하는
  매크로 트레이딩.
- **스탠리 드러켄밀러**: 매크로 판단 + 확신이 클 때 집중 베팅.

## 4. 추세추종·퀀트 계열 (단기, 자동화 친화적)

- **제시 리버모어**: 추세 추종 + 피라미딩 + 손절 규율의 초기 체계화.
- **터틀 트레이더(리처드 데니스)**: 완전 규칙 기반 추세추종 시스템. 지금
  구현 중인 단기 축의 기본 뼈대.
- **짐 사이먼스(르네상스 테크놀로지)**: 통계적 패턴 기반 완전 정량 퀀트.
- **에드 세이코타**: 추세추종 + 리스크관리 + 트레이딩 심리.

## 시장 국면별 참고 스타일

| 시장 상황 | 참고 스타일 |
|---|---|
| 강세장 초입, 실적 개선 구간 | 린치·오닐·미너비니 |
| 고평가·과열 구간 | 막스·소로스 (리스크 축소) |
| 침체·저평가 구간 | 그레이엄·버핏 |
| 매크로 변동성(금리/환율) | 소로스·드러켄밀러 |
| 방향성 불분명, 변동성 장세 | 달리오 (자산배분) |
| 규칙 기반 자동화 신호 | 터틀·사이먼스 |

## 통합 전략 초안

- **장기 축** — 가치·우량주 스크리닝 (분기 리밸런싱)
- **중기 축** — 성장 모멘텀 스크리닝 (주간~월간 점검)
- **단기 축** — 규칙 기반 추세추종 + 이벤트 자동 감지 (실시간)
- **국면 전환 신호** — 매크로 지표로 세 축의 비중 조절

자금 배분: 장기:중기:단기 = 균형 배분(각 30~40%).
